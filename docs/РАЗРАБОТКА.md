# MiniPOS — техническое описание (для разработки)

Инструкция для пользователей — в [README.md](../README.md).


Программа учёта для магазина корейской косметики **mizon yalyan**: касса (розница и опт), склад, продажи,
оптовые клиенты с условиями закупа, скидки и подарки, отчёты, ИИ-чат и Telegram-бот.
Работает на одном компьютере, **интернет не нужен** (кроме ИИ через интернет и Telegram).

---

## 1. Установка как обычная программа

### Mac (собрать у себя, 3–5 минут)
```bash
cd ~/Downloads/minipos
bash build_mac.sh
```
Откроется папка с **MiniPOS.app** — перетащите её в «Программы». Дальше просто открываете двойным кликом:
программа сама запускается в своём окне, терминал не нужен.

- Данные (база, настройки, копии) лежат в **Документы/MiniPOS**. Скрипт сам перенесёт туда вашу текущую базу.
- Закрыли окно — программа остановилась.

### Windows (собирает GitHub, см. раздел 8)
Скачайте `MiniPOS-windows.zip`, распакуйте, например, в `C:\MiniPOS`, запустите `MiniPOS.exe`.
- При первом запуске на рабочем столе появится ярлык **MiniPOS**.
- Если Windows покажет «Windows защитила ваш компьютер» → **Подробнее → Выполнить в любом случае**.
- Данные лежат рядом с программой: `minipos.db`, `settings.env`, `backups`.
- Автозапуск при включении компьютера: `Win+R` → `shell:startup` → скопируйте туда ярлык MiniPOS.

### Для разработки (из кода)
```bash
cd ~/Downloads/minipos
python3.13 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py          # → http://127.0.0.1:8000
.venv/bin/python -m pytest -q    # тесты
```

## 2. Свой каталог из Excel (вкладка «Товары»)

1. **Скачать шаблон** → заполнить: Название, Категория, Штрихкод, Закупка, Опт и/или Розница, Остаток, Минимум.
   Колонки можно расставить в любом порядке, названия колонок распознаются («Наименование», «Кол-во», «Оптовая цена»…).
2. **Выбрать файл** (.xlsx или .csv) → появится **предпросмотр**: что будет создано, обновлено, где ошибки.
3. **Загрузить** — строки с ошибками пропускаются, остальное записывается.

- Если указан только Опт — розница посчитается (опт × 1,5); только Розница — посчитается опт.
- Товар, который уже есть (тот же штрихкод или то же название), **обновляется**; пустые ячейки ничего не меняют.
- Категории создаются сами. Остатки записываются в историю склада («Импорт из Excel»).
- Подходит и файл из «Экспорт в Excel» (лист Products): выгрузили → поправили цены → загрузили обратно.

**Пустая база.** Собранная программа (.exe / .app) при первом запуске начинается **без тестовых данных**.
При запуске из кода тестовые товары и оптовики создаются (`DEMO_DATA=1` в `settings.env`; `0` — пустая база).

## 3. Опт и розница

- У каждого товара есть **закупочная**, **оптовая** и **розничная** цена.
- **Розница = опт × 1,5**, округлённая до 100 ₸. При добавлении товара достаточно указать опт — розница посчитается.
  Коэффициент и округление меняются в `settings.env` (`RETAIL_MARKUP`, `RETAIL_ROUND`).
- Кнопка **«Пересчитать розницу»** (вкладка «Товары») пересчитывает все розничные цены по коэффициенту.
  Значок **≠** у цены — розница отличается от «опт × коэффициент» (например, задана вручную).
- В кассе переключатель **Розница / Опт**. В режиме «Опт» выбирается оптовый клиент, цены — оптовые.
- В «Продажах» видно тип продажи и клиента, есть фильтры. В Dashboard — выручка отдельно по рознице и опту.

## 4. Оптовые клиенты (вкладка «Оптовики»)

Условия (меняются в `settings.env`):
- **первый закуп — от 100 000 ₸** (`WHOLESALE_FIRST_MIN`) — меньше программа не даст оформить;
- **затем каждый календарный месяц — от 30 000 ₸** (`WHOLESALE_MONTHLY_MIN`). Месяц первого закупа засчитан.

Статусы:
| Статус | Значит |
|---|---|
| 🔴 Нарушил условие | в прошлом месяце закупил меньше минимума (строка подсвечена) |
| 🟠 Под угрозой | до конца месяца ≤ 7 дней, а минимум ещё не набран |
| ⚪ В процессе | в этом месяце минимум ещё не набран |
| 🟢 Выполняет | минимум этого месяца набран |
| Нет закупов | клиент ещё не делал первый закуп |

Для каждого: сумма за месяц с полосой прогресса, всего куплено, дата и время последнего закупа, какие месяцы не выполнены.
Кнопка «Продажи» открывает все продажи клиента. Возвраты в условия не засчитываются.

## 5. Скидки и подарки (касса)

- **Скидка на чек**: кнопки 5% / 10% / 15% или сумма в ₸. Максимум — 30% (`MAX_DISCOUNT_PERCENT`), защита от опечатки.
- **Подарок**: кнопка 🎁 у позиции отдаёт 1 шт. в подарок (0 ₸). Кнопка ↩ возвращает её в оплату.
  Подарок списывается со склада, а его **себестоимость учитывается в прибыли** — видно, сколько стоят подарки.
- В чеке печатаются сумма, скидка и строки «ПОДАРОК». В Dashboard — сумма скидок и подарков за период.

## 6. ИИ-помощник

Вкладка **ИИ-чат** и Telegram-бот. Изменения — только после кнопки «Подтвердить».

Бесплатно (Ollama): установите с **ollama.com/download**, затем в терминале `ollama pull qwen2.5:3b`
и в `settings.env` → `AI_MODEL=qwen2.5:3b` (для 8 ГБ памяти; при 16 ГБ+ лучше `qwen2.5:7b`).

Через OpenAI (платно, умнее) — в `settings.env`:
```
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=<модель>
AI_API_KEY=sk-...
```

Что понимает: остатки, выручка/прибыль за период, **что продаётся хуже всего** (включая товары без продаж),
**какие оптовики не выполнили условие**, приход, списание, цены (опт/розница), новый товар,
продажа (в т.ч. оптовому клиенту, со скидкой и подарком), возврат.

## 7. Telegram-бот

1. **@BotFather** → `/newbot` → получите токен → `settings.env` → `TELEGRAM_BOT_TOKEN=...`
2. Перезапустите MiniPOS, напишите боту `/start` — он покажет ваш **Telegram ID**.
3. `settings.env` → `TELEGRAM_ALLOWED_IDS=ваш_ID` → перезапуск.

Команды: `/low`, `/today`, `/reset`; остальное — обычным текстом. Работает, пока включён компьютер с MiniPOS.

## 8. Сборка через GitHub (Windows и Mac)

Один раз:
```bash
cd ~/Downloads/minipos
git init && git add . && git commit -m "MiniPOS"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/minipos.git
git push -u origin main
```
`minipos.db`, `settings.env` и копии на GitHub **не попадают** (`.gitignore`).

Новая версия:
```bash
git add . && git commit -m "обновление"
git tag v0.3 && git push && git push origin v0.3
```
Через ~10 минут в **Releases** появятся `MiniPOS-windows.zip` и `MiniPOS-mac.zip`.

Mac-версия, скачанная из интернета: при первом открытии macOS скажет, что разработчик не проверен →
**Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»** (один раз).

**Обновление программы:** замените файлы программы, **кроме** `minipos.db`, `settings.env`, `backups`.
База от старой версии обновится сама при запуске — данные сохраняются.

## 9. Без интернета

Касса, склад, продажи, оптовики, отчёты, Excel и ИИ через Ollama работают **полностью без интернета** —
всё хранится на компьютере. Когда интернет появится:
- Telegram-бот сам получит сообщения, отправленные за это время;
- копии базы в папке Google Диска / iCloud (`BACKUP_DIR`) выгрузятся в облако их программой синхронизации.

Без интернета не работают только ИИ через OpenAI и Telegram.

## 10. Резервные копии
Каждый день база копируется в `backups` (30 дней). Можно указать папку Google Диска: `BACKUP_DIR=...`.
Восстановить: закройте программу и замените `minipos.db` нужной копией.

## Тестовые данные
Названия и розничные цены — из каталога mizon yalyan. Закупочные цены, остатки, штрихкоды и
**оптовики («Косметолог Айгерим», «Салон Beauty Room», «ИП Ким») — тестовые**.
Чтобы начать с чистой базы — удалите `minipos.db` (появятся снова тестовые товары; клиентов можно скрыть кнопкой ✕).

## Структура
```text
minipos/
├── desktop.py            запуск как программы (окно) — из него собирается MiniPOS.app / .exe
├── build_mac.sh          сборка MiniPOS.app на Mac
├── run.py                запуск для разработки
├── app/
│   ├── main.py           REST API
│   ├── services.py       продажа (опт/розница, скидки, подарки), возврат, склад, условия оптовиков
│   ├── reports.py        отчёты
│   ├── importer.py       загрузка каталога из Excel / CSV
│   ├── system.py         ярлык и автозапуск
│   ├── ai.py             ИИ-помощник и его инструменты
│   ├── telegram_bot.py   Telegram-бот
│   ├── backup.py         резервные копии
│   ├── config.py         настройки (settings.env)
│   ├── db.py             база и автообновление её структуры
│   ├── models.py, seed.py
│   └── static/           интерфейс
├── tests/                38 автотестов
└── .github/workflows/build.yml   сборка Windows и Mac на GitHub
```
