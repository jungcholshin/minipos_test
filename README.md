# MiniPOS — инструкция

**MiniPOS** — программа для магазина: касса (розница и опт), склад, продажи, оптовые клиенты,
скидки и подарки, отчёты и выгрузка в Excel.

Программа работает **на вашем компьютере, без интернета**. Все данные хранятся у вас и никуда не отправляются.

---

## Установка на Windows

### Шаг 1. Скачайте программу
Откройте ссылку, которую вам прислали, и скачайте файл **`MiniPOS-windows.zip`**.

### Шаг 2. Распакуйте
1. Откройте папку «Загрузки» и найдите `MiniPOS-windows.zip`.
2. Нажмите на него **правой кнопкой мыши** → **«Извлечь всё…»**.
3. В поле пути напишите **`C:\`** и нажмите **«Извлечь»**.
4. Появится папка **`C:\MiniPOS`** — в ней программа и, позже, все ваши данные.

> Не запускайте программу прямо из zip-архива и не храните её в «Загрузках» —
> оттуда файлы легко случайно удалить вместе с данными.

### Шаг 3. Запустите
1. Откройте папку `C:\MiniPOS`.
2. Дважды нажмите на **`MiniPOS.exe`**.
3. Если появится синее окно **«Windows защитила ваш компьютер»** — нажмите **«Подробнее»** →
   **«Выполнить в любом случае»**. Это бывает с любой новой программой; при следующих запусках окна не будет.
4. Откроется окно MiniPOS.

### Шаг 4. Ярлык на рабочем столе
При первом запуске на рабочем столе **сам появится ярлык MiniPOS**. Дальше открывайте программу двойным кликом по нему.

Если ярлыка нет: в программе нажмите **⚙** (вверху справа) → **«Создать ярлык на рабочем столе»**.

### Шаг 5. Автозапуск при включении компьютера (по желанию)
В программе нажмите **⚙** → поставьте галочку **«Запускать MiniPOS при включении компьютера»**.
Теперь программа будет открываться сама. Снять галочку можно там же.

## Первый запуск: загрузите свой каталог

Программа начинает работу с пустой базой. Товары проще всего загрузить из Excel:

1. Откройте вкладку **«Товары»**.
2. Нажмите **«Скачать шаблон»** — скачается файл Excel.
3. Заполните его: одна строка — один товар.

   | Колонка | Обязательно | Пример |
   |---|---|---|
   | Название | да | Beauty of Joseon Relief Sun SPF50+ |
   | Категория | нет | SPF |
   | Штрихкод | нет | 8809738316139 |
   | Закупка | желательно | 3600 |
   | Опт | одна из цен | 4330 |
   | Розница | одна из цен | 6500 |
   | Остаток | нет | 20 |
   | Минимум | нет | 5 |

   Можно указать только **Опт** — розница посчитается сама (опт × 1,5). Можно только **Розницу** — посчитается опт.
4. Вернитесь в программу → **«Выбрать файл»** → выберите заполненный файл.
5. Проверьте предпросмотр: зелёным — новые товары, красным — строки с ошибками (они пропустятся).
6. Нажмите **«Загрузить»**.

Подойдёт и ваша собственная таблица — программа сама узнаёт колонки «Наименование», «Кол-во», «Оптовая цена» и т.п.
Если загрузить файл ещё раз, существующие товары **обновятся**, а не задвоятся.

Товары можно добавлять и по одному: вкладка «Товары» → «Новый товар».

## Ежедневная работа

### Продажа (вкладка «Касса»)
1. Найдите товар: начните вводить название или отсканируйте штрихкод сканером.
2. Нажмите на товар — он добавится в чек. Кнопки **−** / **+** меняют количество.
3. Выберите способ оплаты и нажмите **«ОПЛАТИТЬ»**. Остатки на складе уменьшатся сами.

**Скидка** — кнопки 5% / 10% / 15% под чеком или своя сумма в ₸ (не больше 30%).

**Подарок** — кнопка 🎁 у товара в чеке отдаёт 1 шт. бесплатно. Кнопка ↩ возвращает её в оплату.

### Оптовая продажа
1. В кассе переключите **«Розница» → «Опт»**.
2. Выберите оптового клиента (добавляются на вкладке **«Оптовики»**). Цены станут оптовыми.
3. Первый закуп клиента — от **100 000 ₸**, затем каждый месяц — от **30 000 ₸**.
   На вкладке «Оптовики» видно, кто выполняет условие, а кто нет (красным).

### Поступление товара (вкладка «Склад»)
Напротив товара → **«+ Поступление»** → введите количество.
Если пересчитали товар и цифра не совпала — **«Корректировка»** → введите фактический остаток.

### Возврат (вкладка «Продажи»)
Найдите продажу → **«Возврат»**. Товар вернётся на склад, продажа останется в истории с пометкой «Возврат».

### Отчёты
- **Dashboard** — выручка (розница и опт отдельно), прибыль, скидки, подарки, топ товаров, что заканчивается.
- **«Экспорт в Excel»** — все продажи, товары и клиенты одним файлом.

## Где хранятся данные и как не потерять их

Всё лежит в папке программы `C:\MiniPOS`:

| Файл / папка | Что это |
|---|---|
| `minipos.db` | **ваша база** — товары, продажи, клиенты |
| `backups` | автоматические копии базы за последние 30 дней (одна в день) |
| `settings.env` | настройки (цены, условия для оптовиков и т.д.) |

**Совет:** раз в неделю копируйте `minipos.db` на флешку или в Google Диск.

**Восстановить из копии:** закройте программу → в папке `backups` возьмите нужный файл →
скопируйте его в `C:\MiniPOS` и переименуйте в `minipos.db` (старый файл замените).

**Перенести на другой компьютер:** установите программу на новом компьютере (шаги 1–3),
закройте её и скопируйте туда `minipos.db` и `settings.env` со старого.

## Обновление программы

1. Закройте MiniPOS.
2. Скачайте новый `MiniPOS-windows.zip` и распакуйте его в `C:\`, **заменяя файлы**.
3. Файлы `minipos.db`, `settings.env` и папка `backups` при этом **не трогаются** — данные сохранятся.
4. Запустите MiniPOS. Если в новой версии появились новые поля, база дополнится сама.

Номер версии виден рядом с названием программы и в **⚙**.

## Настройки (по желанию)

Откройте файл `C:\MiniPOS\settings.env` **Блокнотом**, измените число и сохраните. Затем перезапустите программу.

| Строка | Что меняет | По умолчанию |
|---|---|---|
| `RETAIL_MARKUP=1.5` | розница = опт × это число | 1,5 |
| `RETAIL_ROUND=100` | округление розничной цены, ₸ | 100 |
| `WHOLESALE_FIRST_MIN=100000` | минимальный первый закуп оптовика, ₸ | 100 000 |
| `WHOLESALE_MONTHLY_MIN=30000` | минимальный закуп оптовика в месяц, ₸ | 30 000 |
| `MAX_DISCOUNT_PERCENT=30` | максимальная скидка на чек, % | 30 |
| `BACKUP_DIR=` | папка для копий (например, папка Google Диска) | папка `backups` |

ИИ-чат и Telegram-бот — необязательные функции, они настраиваются там же (описание внутри файла).

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Программа не открывается после двойного клика | Подождите 10–20 секунд — первый запуск дольше. Проверьте, нет ли уже открытого окна MiniPOS. |
| Вместо окна программы открылся браузер | Это нормально — программа работает в браузере. Чтобы было отдельное окно, установите **Microsoft Edge WebView2** с сайта Microsoft. |
| Антивирус блокирует MiniPOS.exe | Добавьте папку `C:\MiniPOS` в исключения антивируса. |
| Пропали данные после обновления | Скорее всего, программу распаковали в другую папку. Найдите старую `minipos.db` и скопируйте её в новую папку. |
| Другое | Пришлите файл `C:\MiniPOS\minipos.log` — в нём записаны ошибки. |

## Установка на Mac

1. Скачайте **`MiniPOS-mac.zip`**, откройте его — появится **MiniPOS.app**.
2. Перетащите **MiniPOS.app** в папку **«Программы»**.
3. Откройте её. Если macOS напишет, что разработчик не проверен:
   **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»** (один раз).
4. Данные хранятся в папке **Документы → MiniPOS**.
5. Автозапуск — **⚙** в программе. Для быстрого доступа перетащите MiniPOS в Dock.
